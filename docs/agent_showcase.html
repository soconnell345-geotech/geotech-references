Example: Micropile Bond Zone Design

Agent Conversation
User
I need to design a Type B micropile in medium-dense gravel. What bond stress should I use, and what's the required bond length for a 900 kN design load with a 178 mm drill hole?
Tool
micropile_agent("table_5_3_alpha_bond", {"soil_type": "gravel", "micropile_type": "B"})
{ "soil_type": "gravel", "soil_description": "Gravel (some sand), medium-very dense", "micropile_type": "B", "alpha_bond_min_kpa": 120, "alpha_bond_max_kpa": 360 }
Agent
Per FHWA-NHI-05-039, Table 5-3, the grout-to-ground ultimate bond stress for a Type B micropile in medium to very dense gravel is 120 to 360 kPa.

Using the conservative lower bound of 120 kPa with your 178 mm drill hole:
  Bond length = 900 kN / (pi × 0.178 m × 120 kPa) = 13.4 m

Using a mid-range value of 240 kPa:
  Bond length = 900 kN / (pi × 0.178 m × 240 kPa) = 6.7 m

I recommend using the conservative value for preliminary design and confirming with a load test. Would you like me to also check the structural capacity of the casing?
